# 💧 Smart Water Leak Detector

A simple web-based prototype for detecting abnormal
water flow and pressure conditions in pipelines.

## Problem

Water leakage in pipelines can result in significant
water wastage and infrastructure damage.

## Solution

The system monitors:

- Flow rate
- Pipeline pressure
- Water consumption

Abnormal readings trigger a leak warning.

## Technologies

- HTML
- CSS
- JavaScript

## Features

- Real-time simulated sensor readings
- Leak detection
- Pipeline visualization
- Water usage monitoring
- Alert system

## Future Scope

The prototype can be connected to:

- ESP32
- Water flow sensor
- Pressure sensor
- IoT cloud platform
- Mobile notification system

## How to Run

Download the repository and open:

`index.html`

in any modern web browser.
